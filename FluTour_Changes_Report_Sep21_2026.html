Changes Made Today

Bug Fix

Login Persistence

Both apps required re-entering credentials on every launch. Fixed by switching from authStateChanges().first (async, emits null first) to FirebaseAuth.instance.currentUser (synchronous, immediately available after Firebase.initializeApp()).

flu_tour_passenger/lib/main.dart flu_tour_driver/lib/main.dart
New Feature

Geocoding Search — Worldwide

Passenger booking now has a full-screen live search for pickup and drop-off locations. Uses Nominatim (OpenStreetMap) API with debounced 450ms search, worldwide coverage with no API key required.

flu_tour_passenger/lib/route_service.dart flu_tour_passenger/lib/main.dart flu_tour_passenger/lib/app_localizations.dart
Bug Fix

Live Driver GPS Tracking During Rides

Passenger's map was not showing real-time driver position during active trips. Fixed by ensuring DriverLocationService.startBroadcasting() always runs from ActiveRideScreen and calling broadcastPosition() on every GPS fix — writing directly to Firebase Realtime Database.

flu_tour_driver/lib/location_service.dart flu_tour_driver/lib/main.dart database.rules.json firebase.json
New Feature

Audio Notifications

Added sound alerts using the audioplayers package with programmatically generated PCM WAV tones (no bundled audio files). Driver hears a beep on new trip requests; passenger hears an alert when a driver makes an offer or sends a counter-offer.

flu_tour_passenger/lib/sound_service.dart flu_tour_driver/lib/sound_service.dart flu_tour_passenger/pubspec.yaml flu_tour_driver/pubspec.yaml

Commission Update

FluTour Commission: 15% → 20%

Driver earnings calculation updated from 85% to 80% of agreed fare. Reflected in the trip completion dialog and driver localizations.

flu_tour_driver/lib/main.dart flu_tour_driver/lib/app_localizations.dart
New Feature

Passenger Count Selection

Passengers can now specify the number of travellers (1–20) when booking a trip using a +/− stepper on the booking form. The count is stored in the Firestore trip document and displayed on the driver's trip request card and active ride screen.

UI Fix

Driver Splash Screen — Always English

The green splash screen in the driver app now always displays in English ("FluTour Driver", "Your ride, your earnings", "Get Started") regardless of the app's language setting (English or Arabic).
